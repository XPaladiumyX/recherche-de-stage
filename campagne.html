Activer l'envoi en 5 étapes

Le site GitHub Pages reste un annuaire statique. Pour envoyer de vrais mails avec pièces jointes, un petit serveur local doit tourner sur ton ordinateur.

1
Installer Node.js

Si ce n'est pas déjà fait, installe Node.js 18 ou plus depuis nodejs.org.

2
Installer le serveur

Ouvre un terminal dans le dossier du projet :

cd server npm install
3
Configurer Gmail ou Outlook

Crée un mot de passe d'application, puis copie le fichier d'exemple et remplis tes identifiants.

copy .env.example .env # puis édite server/.env

Gmail : mot de passe d'application · Outlook : sécurité du compte

4
Démarrer le serveur

Le plus simple : double-clique sur server/start.bat. Sinon, dans le dossier server :

npm start

Garde la fenêtre ouverte pendant l'envoi. Le serveur écoute uniquement sur ton PC.

5
Ouvrir la version locale

Clique sur le bouton ou ouvre cette adresse :

http://localhost:3001/campagne.html

La page détecte automatiquement le serveur et débloque l'envoi.

Ne mets jamais server/.env sur GitHub. Le serveur n'écoute que sur 127.0.0.1 et les données restent dans server/data et server/uploads.

Pièces jointes

Ajoute ton CV, ta lettre de motivation et éventuellement ton carnet d'évaluation. Les fichiers restent sur ton PC. Limite : 10 Mo par fichier et 20 Mo au total.

Aucun fichier ajouté pour l'instant. Ils seront joints à chaque mail de la campagne.
